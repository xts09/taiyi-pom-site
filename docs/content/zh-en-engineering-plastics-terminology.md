# 台益中英工程塑料术语库 v1

状态：工作稿，供中文与英文页面统一用词使用
范围：POM 为核心，同时覆盖 PA6、PA66、PPA 页面共用的材料、性能、加工、验证与询盘术语
本版不直接改动运行时文案、牌号数据或 SEO metadata

## 1. 建库目的

这份术语库解决四类问题：

1. 中文行业习惯与英文技术表达不能逐字互译。
2. 相关但不等价的性能词容易被当成同义词，例如“耐磨”和“低摩擦”。
3. `review`、`screening`、`validation` 等英文词在现有页面中承担了过多含义。
4. 页面需要既能覆盖客户搜索语言，又不形成未经数据支持的性能、认证或替代承诺。

## 2. 来源优先级

术语采用以下优先级。低优先级来源不得推翻高优先级技术含义。

1. 台益已确认的产品目录、TDS、证书范围和项目事实。
2. 现行 ISO/GB/ASTM 测试方法与材料命名。
3. 国际树脂原厂、改性材料厂商的官方产品页和设计手册。
4. 国内改性材料厂商的官方产品页与应用页。
5. 客户搜索语言、行业俗称和经销商页面，仅用于别名与 SEO 入口，不作为技术定义。

## 3. 国内外表达对照结论

### 3.1 国内页面的优势

- 常用“材料—性能—应用”三段式，适合快速浏览。
- 家族名称短，例如“增强 POM”“增韧 POM”“通用 POM”。
- 客户熟悉“加纤、赛钢、高抗冲、低翘曲”等入口词。
- 更常以零部件和应用系统组织材料，而不是只展示树脂化学名称。

### 3.2 国内页面的风险

- “增强、填充、增韧、高抗冲”有时混用。
- “耐磨、耐摩擦、低摩擦、自润滑”经常被当成同义词。
- “导电、抗静电、ESD”经常缺少测试方法和电阻率边界。
- 中文页面与英文页面之间也可能出现技术误译。

例：金发科技的中文 POM 页面将 ULTRON-GT** 标为“增强 POM”，而英文页面将同一材料标为 `Toughened POM`，但两页列出的方向仍是高强度与高模量。本术语库按技术含义采用 `glass-fiber-reinforced POM`，不沿用该英文标签。

### 3.3 国际页面的优势

- 更严格区分 `wear`、`friction`、`sliding properties` 和 `tribological performance`。
- 更严格区分 `antistatic`、`static dissipative` 与 `electrically conductive`。
- 常将 `filled`、`reinforced`、`impact modified` 和 `unfilled` 作为独立属性。
- 更常说明试验条件、摩擦副、测量方法与最终适用性边界。

### 3.4 国际页面的风险

- 原厂品牌术语不一定适合成为台益的通用家族名称。
- `solution`、`approved`、`drop-in replacement` 等词带有具体服务或合规语境，不能泛化。
- 英文原厂页面面向全球市场，中文页面仍需保留国内客户实际搜索的简称。

## 4. 使用状态

- **规范词**：页面标题、正文、导航和 CTA 优先使用。
- **入口词**：可用于搜索覆盖、括注、FAQ 或首次解释，不作为技术标题首选。
- **受限词**：只有目录、TDS、证书或项目证据明确支持时才能使用。
- **禁用词**：会造成自动适用、等效替代、认证或性能保证含义，默认不使用。

### C. 力学、摩擦、尺寸与环境性能

| 中文规范词 | Preferred English | 可接受别名／入口词 | 使用规则与边界 |
|---|---|---|---|
| 拉伸强度 | tensile strength | tensile stress at break / yield | 必须与实际试验项目一致；不要把屈服应力、断裂应力都简化成拉伸强度。 |
| 拉伸模量 | tensile modulus | modulus in tension | 不写成 `tensile stiffness` 代替数据字段。 |
| 弯曲强度 | flexural strength | bending strength | 技术数据优先 `flexural strength`。 |
| 弯曲模量 | flexural modulus | modulus in flexure | 不与拉伸模量互换。 |
| 冲击强度 | impact strength | impact performance | 必须保留缺口／无缺口、Charpy／Izod 与测试条件。 |
| 缺口冲击强度 | notched impact strength | notched Charpy impact strength; notched Izod impact strength | 必须按实际测试方法选择 Charpy 或 Izod，不能省略后混用数值。 |
| 断裂伸长率 | elongation at break | strain at break | 与屈服伸长率区分。 |
| 强度 | strength | mechanical strength | 说明拉伸、弯曲或具体载荷，避免只写“高强”。 |
| 刚度 | stiffness | rigidity（入口词） | 工程正文优先 `stiffness`；`rigidity` 可用于概述但不替代模量。 |
| 韧性 | toughness | impact toughness | 不是冲击强度的直接同义词；需要结合冲击、伸长和失效方式理解。 |
| 刚韧平衡 | stiffness–toughness balance | balance of stiffness and toughness | 不使用模糊的 `balanced performance` 代替具体权衡。 |
| 耐磨性 | wear resistance | resistance to wear | 指材料抵抗磨损；不等于低摩擦。 |
| 低磨耗 | low wear | reduced wear | 需要磨耗量、磨损率或对比试验支持；不要泛写 `wear-free`。 |
| 摩擦系数 | coefficient of friction (COF) | friction coefficient | 必须结合静摩擦／动摩擦、摩擦副、压力、速度与环境理解。 |
| 低摩擦 | low friction | reduced friction | 不自动等于耐磨、自润滑或低噪声。 |
| 滑动性能 | sliding properties | slip properties | 用于概述运动界面表现；仍需摩擦副和试验条件。 |
| 摩擦学性能 | tribological performance | tribological properties | 同时涉及摩擦、磨损、润滑、接触条件；专业页面使用，不在普通 CTA 滥用。 |
| 摩擦学改性 | tribologically modified | friction-and-wear modified | 只有明确的摩擦学改性体系时使用。 |
| 自润滑 | self-lubricating | internally lubricated | 受限词。需要配方事实和相应测试；禁止从 POM 基础滑动特性自动推导。 |
| 干摩擦运行 | dry-running | dry sliding | 指无外部润滑条件，不表示所有干摩擦系统都适用。 |
| 粘滑 | stick-slip | jerky sliding（解释性） | 专业词优先 `stick-slip`；首次可解释为不连续滑动。 |
| 异响／啸叫 | squeak / noise | operating noise | `squeak` 只对应摩擦啸叫；一般噪声使用 `noise`。 |
| 疲劳强度／耐疲劳性 | fatigue strength / fatigue resistance | fatigue performance | 循环次数、应力与环境必须定义。 |
| 抗蠕变性 | creep resistance | resistance to creep | 与短期刚度、HDT 不等价。 |
| 尺寸稳定性 | dimensional stability | dimensional control | 表示综合结果；不等同于低收缩或低翘曲。 |
| 成型收缩率 | molding shrinkage | mold shrinkage | 必须带方向、试样、工艺或测试条件；不能写成固定零部件收缩。 |
| 低收缩 | low shrinkage | reduced molding shrinkage | 受限比较词，需要相同条件下的数据或明确家族定位。 |
| 翘曲 | warpage | warping | `warpage` 适合名词和数据语境；不与收缩直接互换。 |
| 低翘曲 | low warpage | reduced warpage tendency | 应写成筛选方向，不保证实际零部件不翘曲。 |
| 各向异性 | anisotropy | directional property variation | 纤维取向、流动方向和试样条件相关。 |
| 纤维取向 | fiber orientation | fibre orientation | 网站默认美式拼写 `fiber`；引用英式资料时可保留 `fibre`。 |
| 热变形温度（HDT） | heat deflection temperature (HDT) | temperature of deflection under load | 标准名称更接近 `temperature of deflection under load`；网站字段可保留行业通用 `HDT`，必须带载荷与方法。 |
| 耐热性 | heat resistance | thermal resistance | 不从单一 HDT 自动推导长期使用温度。 |
| 长期耐热性 | long-term heat resistance | heat-aging resistance | 与短期 HDT 区分，需老化条件或长期数据。 |
| 耐热老化 | heat-aging resistance | thermal-aging resistance | 必须有温度、时间和保留率语境。 |
| 耐候性 | weather resistance | weatherability | 不仅是 UV；户外适用仍需实际暴露条件验证。 |
| 抗紫外性能 | UV resistance | UV stability | `UV stabilized` 描述材料改性，`UV resistance` 描述性能方向。 |
| 耐化学性 | chemical resistance | chemical compatibility | 应说明介质、浓度、温度、应力和接触时间。 |
| 吸水率 | water absorption | moisture absorption | 按实际测试字段选择；不能仅用“低吸水”替代数值和条件。 |

|---|---|---|---|
| 抗静电 | antistatic | anti-static | 描述减少静电积聚的材料方向；不得与静电耗散或导电混用。统一拼写优先 `antistatic`。 |
| 永久抗静电 | permanently antistatic | permanent antistatic | 受限词。必须有对应改性技术及耐久性证据，不能只凭一次电阻测试使用。 |
| 静电耗散 | static dissipative | electrostatic dissipative | 表示受控泄放电荷的性能方向；必须定义目标电阻范围和测试条件。 |
| 导电 | conductive | electrically conductive | 材料页面优先 `electrically conductive` 消除热导歧义；短标题可用 `conductive`。 |

| 表面电阻率 | surface resistivity | surface resistance（不同量） | 电阻率与电阻不是同一测量量；必须按目录原字段与方法使用。 |
| 体积电阻率 | volume resistivity | volumetric resistivity | 优先行业通用 `volume resistivity`。 |
| 电阻范围 | target resistance range | resistivity range | 根据实际测量量选择 resistance 或 resistivity，不能混写。 |
| 电荷衰减 | charge decay | static decay | 与表面电阻率相关但不是同一测试。 |
| 电荷泄放路径 | charge-dissipation path | grounding path; discharge path | `grounding path` 只有系统确实接地时使用。材料只是系统的一部分。 |

### E. 流动、加工与技术数据

| 中文规范词 | Preferred English | 可接受别名／入口词 | 使用规则与边界 |
|---|---|---|---|
| 熔体质量流动速率（MFR） | melt mass-flow rate (MFR) | melt flow rate | ISO 1133 技术字段优先 MFR；必须带温度与负荷。 |
| 熔融指数（MFI） | melt flow index (MFI) | melt index | 作为行业俗称和历史目录字段保留；新技术说明优先 MFR，不把 MFI 与 MVR 混用。 |
| 熔体体积流动速率（MVR） | melt volume-flow rate (MVR) | volume melt-flow rate | 填充与未填充材料比较时尤其要与 MFR 区分。 |
| 流动性 | flowability | flow behavior; melt flow | 概述使用；不能仅凭 MFR 判断复杂模具充填。 |
| 高流动性 | high flowability | high flow | 与试验条件、壁厚和流长结合；禁止写 `flows easily` 作为技术结论。 |
| 熔体黏度 | melt viscosity | viscosity | 采用网站统一“黏度”；中文搜索别名可覆盖“粘度”。 |
| 流长 | flow length | flow-path length | 应结合壁厚、浇口和压力；不要从 MFR 单独推导。 |
| 流长壁厚比 | flow-length-to-wall-thickness ratio | flow path / wall thickness ratio | 技术资源页使用，普通卡片不必展开。 |
| 薄壁注塑 | thin-wall injection molding | thin-wall molding | 需要定义壁厚和充填条件，不能只凭“高流动”自动标注。 |
| 长流程充填 | long-flow molding | long flow path filling | 中文页面优先描述“长流程／长流长零件”，英文避免 `long-process molding`。 |
| 模具充填 | mold filling | cavity filling | 美式拼写使用 `mold`；不要误写 `moulding filling`。 |
| 成型窗口 | processing window | molding window | 与已确认的加工条件结合；不承诺窗口“宽”除非有数据。 |
| 注塑成型 | injection molding | injection moulding | 网站默认美式拼写 `molding`。 |
| 模具温度 | mold temperature | mold-wall temperature | 按资料原字段使用；原厂设计手册常用 `mold wall temperature`。 |
| 熔体温度 | melt temperature | processing temperature | 不与料筒设定温度直接互换。 |
| 干燥条件 | drying conditions | drying recommendation | POM 与 PA 的吸湿和干燥逻辑不同，按材料和 TDS 使用。 |
| 加工建议 | processing guidance | processing recommendations | 不使用 `processing guarantee`；应引导至 TDS 与试模。 |
| 技术数据表 | technical data sheet (TDS) | datasheet | 首次使用写全称与缩写；按钮可用 `TDS`。 |
| 已发布数据 | published data | available grade data | 仅指网站或资料中已公开的数据。 |
| 数据可用性 | data availability | available data | 表示能否提供，不代表数据足以证明适用性。 |
| 文件可用性 | document availability | available documents | 包括 TDS、SDS、合规文件等实际可提供状态，不写 `full documentation`。 |
| 测试方法 | test method | test standard | 方法、标准、试样和条件应尽可能与数值同列。 |
| 典型值 | typical value | typical property value | 不是规范限值或保证值。英文避免单独写 `specification`。 |
| 规格限值 | specification limit | specified limit | 只有受控规格或合同文件明确时使用。 |

|---|---|---|---|
| 材料初筛 | initial material screening | preliminary screening | 用于从需求缩小材料方向；不等于正式选型结论。 |

| 应用适用性 | application suitability | suitability for the application | 不使用 `application fit` 作为正式结论；只能在完成项目验证后确认。 |
| 适用性评估 | suitability evaluation | suitability assessment | 不等于认证、批准或保证。 |
| 样品 | sample material | material sample; sample pellets | 区分材料粒子样品与注塑零件样品。 |

## 7. 重点禁用与慎用清单

### 默认禁用

- 完美替代 / perfect replacement
- 直接替代 / direct replacement
- 等效牌号 / equivalent grade（除非有经过批准的对等依据）
- 即插即用替代 / drop-in replacement
- 保证适用 / guaranteed fit
- 确保性能 / ensure performance
- 零风险 / risk-free
- 最佳材料 / best material
- 世界领先 / world-leading
- 汽车级 / automotive grade（除非定义具体标准、客户或认证范围）
- 食品级、饮用水级、医疗级（除非具体牌号与证据明确）
- 防火 / fireproof
- 永不磨损 / wear-free
- 永久导电（应写明具体技术和耐久证据）

### 优先改写

| 模糊表达 | 优先改成 |
|---|---|
| 审查材料 | 比较候选牌号的数据、样品和试模条件 |
| 审核应用 | 确认零部件工况与验证要求 |
| 材料方向 | 候选材料家族／改性方向 |

| 适用于 | 可作为候选方向／用于初步筛选 |
| 优异性能 | 具体性能名称及已发布数据 |

| 快速响应 | 直接项目沟通／响应时间按项目确认 |
| 低起订量 | 样品与试产数量按材料和项目条件确认 |

## 8. 写作规则

1. 家族标题写材料方向，不写未经验证的零部件结论。
2. 性能词尽量配合对象：对什么摩擦副耐磨、在哪种载荷下抗冲、测什么电阻率。
3. 中文可以保留客户入口词，但首次出现时落回规范词。
4. 英文使用美式拼写：`fiber`、`mold`、`molding`、`color`。
5. `review` 不再作为万能动词：
   - 缩小范围用 `screen` / `screening`；
   - 比较证据用 `evaluate` / `evaluation`；
   - 核对信息用 `check` / `confirm`；
   - 项目验证用 `validate` / `validation`。
6. `solution` 只在页面确实组合了材料、技术协作和验证路径时使用。
7. 数据名称与测试方法绑定。不同方法、载荷或试样方向的数据不得直接横比。
8. “适用、替代、认证、批准、量产”均属于结果词，必须有对应项目证据。
