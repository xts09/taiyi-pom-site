# Site Visual Rules v1

Taiyi pages should read as a restrained engineering-materials site, not a set of marketing card templates.

- **Rail:** navigation, hero copy, section bodies, lists, cards, and CTAs use the shared site rail. Media can bleed wider only when it supports the material or factory story.
- **Type:** one page H1 per route; section titles stay medium and scannable; body copy uses a darker blue-gray with readable line length; card/list titles stay close to body scale.
- **Kickers:** use small labels sparingly. Avoid repeating blue side bars and tracked uppercase labels on every section.
- **Modules:** directories use light lists or light cards. Explanation sections use prose, image-plus-text, tables, or data blocks. Do not mix heavy cards, tiny lists, and table-like rows for the same navigation purpose.
- **Blue:** use one calm brand blue family. Avoid switching between cyan, purple-blue, heavy royal blue, and gray for the same navigation or hover role.
- **Surfaces:** reduce the ghost-card pattern: avoid pairing bright white cards, 1px borders, large soft shadows, and oversized radius unless the element truly needs a framed surface.
